## ⌨️ Common Git Commands

A quick look at the commands used regularly throughout the labs. See [`05-Git/git-commands.md`](05-Git/git-commands.md) for the complete reference and examples.

| Command | Purpose |
|---------|---------|
| `git init` / `git clone <url>` | Initialize a local repo or clone a remote one |
| `git status` / `git diff` | Check working tree status and unstaged changes |
| `git add <file>` / `git add .` | Stage specific files or all directory changes |
| `git commit -m "message"` | Record staged changes to history |
| `git log` | View commit history |
| `git branch <name>` / `git switch <name>` | Create or switch between branches |
| `git merge <branch>` | Merge another branch into the current one |
| `git remote -v` | List configured remote repositories |
| `git fetch` / `git pull` / `git push` | Sync changes with a remote repository |
